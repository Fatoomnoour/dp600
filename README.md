# محاكي امتحان DP-600 | DP-600 Exam Simulator

منصة تفاعلية باللغة العربية للتحضير لشهادة **Microsoft Fabric Analytics Engineer (DP-600)**: محاكي امتحان، مراجعة سريعة، تحليل النتائج، مراجعة الأخطاء، والمفضلة — تصميم داكن متجاوب RTL.

## المميزات

- **102 سؤال** من ملف الأسئلة المرفوع، بنوعين رئيسيين (اختيار من متعدد) وجداول Yes/No.
- محرك أسئلة يدعم 5 أنواع: **Single** (اختيار واحد)، **Multiple** (متعدد)، **Yes/No** (جدول عبارات)، **Hotspot** (نقر على مناطق الصورة بنسب مئوية)، **Drag & Drop** (سحب مع بديل بالنقر للموبايل).
- مؤقت جلسة، لوحة أسئلة ملونة بحالة الإجابة، حفظ تلقائي في المتصفح (localStorage)، مفضلة، أصوات، صفحات نتائج مع مصفوفة مراجعة لكل سؤال وتفسير الإجابة والمرجع.
- ملاحق الأسئلة: صور صفحات PDF الأصلية لكل سؤال.

## التشغيل محلياً

```bash
npm install
npm run dev        # تطوير
npm run build      # إنتاج إلى dist/
```

## النشر

رفع على الفرع `main` يشغّل `.github/workflows/deploy-pages.yml` تلقائياً ويبني وينشر إلى GitHub Pages على المسار `/dp600/`.
